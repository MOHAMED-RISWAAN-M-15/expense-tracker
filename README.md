## Expense Tracker
This is my Expense Tracker project, built using Python.
I created this project to practise my Python skills and learn how to work with files and JSON. It helps users keep track of their expenses and see where their money is going.
## What can it do?
Add a new expense with its name, amount, and category
View all saved expenses
Calculate total spending
See how much was spent in each category
Edit an existing expense
Delete an expense
Save expenses in a JSON file so the data is available when the program runs again
## Built With
Python
JSON
## How to Run
Make sure Python is installed on your computer.
Download or clone this repository.
Open the project folder in your terminal.
Run the following command:python expense.py
